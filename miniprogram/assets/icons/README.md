# 图标资源

本目录存放可自行替换的 PNG 图标。保持文件名不变即可替换图片，无需修改页面逻辑；文件名区分大小写，使用小写英文和连字符。代码中的引用格式为 `/assets/icons/<文件名>.png`，Tab 图标由 [app.json](../../app.json) 配置。

## 图片规格

- 使用正方形、透明背景 PNG，建议源文件为 96×96 或 128×128 像素；搜索等小图标使用 64×64 也可以。
- 图形在画布中居中，使用一致的线宽与留白；优先线性图标，避免把按钮背景、圆圈底色或文字一起画进图片。
- 同一图标的普通／选中版本保持相同画布、图形大小和位置，避免切换时跳动。
- 页面显示尺寸由各页面／组件的 WXSS 控制，源图片尺寸不等于显示尺寸。PNG 不会随 CSS `color` 自动变色，需在导出图片时设置颜色。
- 替换后重新编译，检查实际大小、透明边缘、清晰度及浅色背景上的对比度；最终以微信开发者工具和真机显示为准。

## 新增或替换检查

1. 替换时沿用原文件名；新增时同步更新页面引用及本说明中的用途表。
2. 检查引用的文件确实存在，扩展名为 `.png`，避免重复扩展名、大小写不一致或误放到其他 assets 子目录。
3. Tab 图标需成对检查普通／选中状态；排序等按钮还需检查禁用状态。
4. 只换图片无需修改权限、接口或业务数据；新增引用或改变显示尺寸时，再修改对应 WXML／WXSS 或配置。
